  1. {% if session.get('lang') == 'de' %}Käufer eröffnet Streitfall mit Beschreibung des Problems{% else %}Buyer opens dispute with description of issue{% endif %}

{% if session.get('lang') == 'de' %}Wenn Käufer recht hat, wird der volle Betrag erstattet (Verkäufer erhält nichts).{% else %}If buyer is right, full amount refunded (seller receives nothing).{% endif %}

{% if session.get('lang') == 'de' %}Zahlung an Verkäufer{% else %}Payment to seller{% endif %}

{% if session.get('lang') == 'de' %}Teilerstattung{% else %}Partial refund{% endif %}

{% if session.get('lang') == 'de' %}Für teilweise gerechtfertigte Streitfälle.{% else %}For partially justified disputes.{% endif %}

  • {% if session.get('lang') == 'de' %}Admin wird innerhalb von 3-5 Werktagen entscheiden.{% else %}Admin will resolve within 3-5 business days of dispute response.{% endif %}
